# Agent instructions

Read and follow these project documents before working:

- `docs/communication-style.md` — how to communicate in this learning project.
- `docs/development-workflow.md` — how to make, test, and document changes.
- `docs/README.md` — where to find the source-of-truth project documents.

Put reusable code in `src/domain_agent/` and tests in `tests/`.

## Referring to Issues and PRs

Whenever you mention an Issue or pull request to Chris, name the repo and give its full link as clickable markdown, for example [domain-check PR #12](https://github.com/successbycs/domain-check/pull/12). Never write a bare number. This applies to every status update, list and summary, not just the first mention.
