# Agreed schema design for Version 1

## Where schemas are defined

- **Python source of truth:** `src/domain_agent/models.py`, using Pydantic.
- **Human-readable explanation:** `docs/report-schema.md`.
- **OpenAI structured output:** generated from the relevant Pydantic model when
  the API call is made.

We do not need a separate hand-written JSON-schema file in Version 1.

## Data flow

```text
Company-description input
        ↓
OpenAI generation response
        ↓
Cloudflare lookup result
        ↓
Python score
        ↓
Complete research report
```

## Models

| Model | Purpose | Main fields |
| --- | --- | --- |
| `CompanyDescriptionInput` | Data supplied to the project | input filename, company description |
| `GeneratedCandidate` | One candidate returned by OpenAI | name, domain, fit reason, clarity, pronunciation, concerns, name-conflict signal, human-review items, LLM comment |
| `CandidateGeneration` | Full OpenAI response | exactly 10 `GeneratedCandidate` items |
| `AvailabilityCheck` | Cloudflare evidence | status, provider, timestamp, price, currency, error |
| `ScoreBreakdown` | Python-calculated points | availability, clarity, pronunciation, association, total |
| `ResearchCandidate` | One completed candidate | generated candidate, availability, score |
| `ResearchReport` | Final output of one run | run metadata, input, 10 completed candidates, evaluations |

## Exact OpenAI candidate structure

```json
{
  "name": "Harbour Bean",
  "domain": "harbourbean.co.nz",
  "fit_reason": "Connects a coffee business with a Wellington harbour setting.",
  "clarity": "good",
  "pronunciation": {
    "rating": "easy_to_say",
    "reason": "Both words are familiar English words."
  },
  "concerns": [],
  "possible_name_conflict": {
    "status": "not_identified",
    "reason": "No specific similarity was identified by the model.",
    "requires_human_review": true
  },
  "human_review_items": [
    "Check real-world business and trademark records."
  ],
  "editorial_comment": "Warm, local, and easy to remember."
}
```

## Fixed allowed values

```text
clarity:
  excellent | good | poor

pronunciation.rating:
  easy_to_say | unclear | hard_to_say

possible_name_conflict.status:
  not_identified | possible
```

## Boundary

OpenAI receives only the company description and the approved prompt. It does
not receive secret keys, Cloudflare settings, Python scores, or later report
metadata.
