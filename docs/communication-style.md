# Communication style

## Audience

Communicate for a beginner who is learning to build a standalone proof of
concept step by step.

## Language

- Use plain English.
- Define an unfamiliar technical term in one short sentence when it first
  appears.
- Avoid unexplained acronyms, jargon, and vague phrases.
- Prefer concrete wording and examples. For example, say “whether a name seems
  memorable and appealing to the intended customers, with a written reason”
  instead of “marketing resonance.”
